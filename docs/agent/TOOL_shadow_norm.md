Normalize facade photos so shadowed walls read with the same colour as lit ones.

  python tools/shadow_norm.py --image photos/ref101/101_stitched_p16.png     --out photos/ref101/101_stitched_p16_lit.png

  python tools/shadow_norm.py --refs photo_refs.json --out-refs photo_refs_lit.json

Method: the brightest percentile of the image is treated as the white wall
reference. Each block gets its own gain from its own bright pixels, the gain map
is smoothed, and every pixel is scaled by it. Shadowed blocks brighten toward
the lit white, so sampled colours describe the material instead of the lighting.

This is for measurement and albedo textures, not for display images.

options:
  -h, --help            show this help message and exit
  --image IMAGE         image file (repeatable)
  --dir DIR             folder of images
  --out OUT             output file (single image) or folder (with --dir)
  --suffix SUFFIX       output name suffix for --dir
  --refs REFS           photo_refs json: normalize every referenced image and
                        write a new refs json
  --out-refs OUT_REFS   where to write the new refs json (default:
                        <refs>_lit.json)
  --block BLOCK         block size in px for the gain map
  --max-gain MAX_GAIN
  --bright-pct BRIGHT_PCT
  --patch-median        use the median of five patch whites (corners + centre)
                        as the white reference
  --patch-frac PATCH_FRAC
                        patch size as a fraction of the shorter side (default
                        0.18)
  --json
