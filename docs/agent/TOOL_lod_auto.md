usage: lod_auto.py [-h] --asset ASSET [--out OUT] [--lod1-ratio LOD1_RATIO]

Generate LOD1/LOD2 candidates from the main mesh of an exported .blend, then check holes.

  python tools/lod_auto.py --project P --asset output/<asset> --check --json

The source .blend is not modified. The candidate is written to
output/<asset>/_lod_auto/<asset>_lod_auto.blend with objects
<asset>_lod_auto, <asset>_lod_auto_LOD1, <asset>_lod_auto_LOD2.
Use the result as a candidate for the generator; verify it with lod_check and in game.

options:
  -h, --help            show this help message and exit
  --asset ASSET         output/<asset> folder or .blend
  --out OUT             candidate folder (default: <asset folder>/_lod_auto)
  --lod1-ratio LOD1_RATIO
                        LOD1 triangle ratio (< 0.5)
  --lod2-tris LOD2_TRIS
                        LOD2 target triangle count
  --max-tris MAX_TRIS   hard cap for the main mesh (default 95000, the kit's
                        warning limit)
  --max-lod1-tris MAX_LOD1_TRIS
                        hard cap for LOD1 (default: half of --max-tris)
  --blender BLENDER     Blender executable
  --check               run lod_check --quick on the candidate
  --check-full          run the full 64-view lod_check
  --no-cap-bottom       do not fill open bottom boundary loops
  --json
